下载脚本文件 或长按复制此直链 → read-frog-lite-via-v1.3.8.user.js

Via 安装步骤

  1. 点上方按钮下载 .user.js 文件
  2. Via 菜单 → 设置 → 脚本
  3. 右上角 ➕ → 本地导入，选择下载的文件
  4. 启用脚本，刷新网页即可看到青蛙悬浮球
