下载脚本文件 或长按复制此直链 → read-frog-lite-via-v1.3.9.user.js 纯文本版（.txt）→ read-frog-lite-via-v1.3.9.txt

Via 安装步骤

  1. 点上方按钮下载 .user.js 文件
  2. Via 菜单 → 设置 → 脚本
  3. 右上角 ➕ → 本地导入，选择下载的文件
  4. 启用脚本，刷新网页即可看到青蛙悬浮球
v1.3.9：多指按压语义统一为「原文 / 译文」二态循环——空闲按压开始翻译；翻译中或已译完按压一步完成「停止翻译 + 显示原文」，不再需要按第二次；停在原文时再按压立即回渲染已有译文（不重新请求）并继续翻译剩余段落。原文视图期间中止在途请求、暂停页面观察器，翻译记录与本地缓存全部保留，来回切换不重复计费；悬浮球「翻译」按钮复用同一套语义，按钮文案随视图变为「显示原文 / 显示译文 / 翻译」；原文视图下切换显示模式只保存偏好不立即重渲染，菜单「恢复原文」仍是彻底还原。手势识别策略不变：多指长按 320ms 触发，300ms 内先后落齐即可，系统吞掉触摸序列不再导致按住无反应，圆形 slop 容差让斜向抖动不误杀，触发后 1.5 秒去抖。本定制版由 ifei 维护，基于上游 Read Frog，GPL-3.0 开源。
